## About me

Hey, I'm Aayan. I'm 18 and I live in Nepal.

I'm just starting out in cybersecurity and coding. Not an expert, and I won't pretend to be. I got hooked because I wanted to know how things actually work, and the fastest way I've found is to break stuff and then figure out how to fix it. Only on my own machine or legal practice labs, always.

Most days it's the Linux terminal, a TryHackMe room, and a Python script that doesn't work yet. I get stuck a lot. That's kind of the point.

**Where I'm at right now**
- Getting comfortable with Linux and the terminal
- Learning how networks work
- Writing small Python scripts to automate things
- Studying web security (OWASP Top 10)
- Trying out Nmap and Burp Suite

**Where I want to get**
A skilled ethical hacker. Not there yet, just a little further than yesterday.
